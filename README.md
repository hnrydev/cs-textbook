# Computer Science Online Textbook

Open `index.html` in a browser to use the textbook.

## Included

- 29 high-level chapters covering the main domains of computer science
- 87 guided reading sections with source-informed depth notes
- Beginner-friendly explanations with objective terminology
- Visual figures and models for each chapter
- Code examples across Python, JavaScript, C, Java, Go, SQL, TypeScript, Assembly, and HTML Canvas
- Searchable chapter navigation
- Persistent local audio reader controls using the browser speech synthesis API
- Curriculum-informed expansion based on ACM/IEEE/AAAI CS2023 and university CS core patterns
- Chapter-level references for further study from university and curriculum sources

## Audio Reader

Use the `Listen` button on any chapter to start reading from that chapter and continue chronologically. Use the audio reader in the bottom-right corner to choose a voice, choose a starting section, adjust pace, pause, resume, or stop.

The audio uses your browser's built-in local speech engine. No external text-to-speech service is required.
