How To Read This Textbook

1. Build the mental model

Each chapter starts with the central idea, then names the abstractions that make the topic manageable.

2. Connect domains

Computer science is not a set of isolated subjects. Algorithms shape databases, operating systems, AI, graphics, and security.

3. Use code as evidence

Code examples are short and language-focused. They are included to make abstract ideas testable.

Curriculum Backbone

University core

Built around the common sequence: programming, discrete math, data structures, algorithms, computer organization, systems, theory, probability, and engineering practice.

CS2023 knowledge areas

Coverage now maps to algorithmic foundations, architecture, AI, data management, programming languages, graphics, HCI, math/stat foundations, networking, OS, parallel/distributed computing, security, society, software, and platforms.

Depth path

Early chapters build intuition; later chapters introduce proof, models, abstraction boundaries, complexity, reliability, and research-level ways of thinking.
